# Roadmap

## Current Portfolio Demo

The current demo should prove that the product is useful, technically sound, visible without credentials, and easy to understand from the public repository.

- Next.js application shell.
- SQLite in-memory synthetic seed data.
- Revenue entries.
- Expense categories.
- Expense entries.
- Monthly goals.
- Cash reserve snapshots.
- Monthly dashboard.
- Financial calculation module.
- Income target simulator.
- CSV export.
- Browser-session mock forms.
- Mobile and desktop QA.

## Version 1.1

- Playwright smoke tests for dashboard, mock entry creation, simulator, and CSV download.
- Better report design.
- More chart breakdowns by category and source.
- Import from CSV.
- Recurring expense templates.
- Monthly close checklist.

## Version 1.2

- Supabase Auth.
- PostgreSQL schema with RLS.
- Authenticated persistence.
- Monthly PDF report.
- Multi-currency support.
- Country-specific tax presets.
- Scenario planning.
- Revenue forecast from pipeline.
- Client-level profitability.

## Commercial Expansion

- Sell as a template for freelancers and consultants.
- Add profession-specific onboarding presets.
- Add branded PDF reports.
- Add shareable accountant/advisor view.
- Add paid hosted version with limits by report history and workspaces.

## Not Planned for Early Versions

- Bank feeds.
- Invoicing.
- Payroll.
- Tax filing.
- Full double-entry accounting.
- Investment recommendations.
